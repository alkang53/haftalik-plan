# Plan Seven

Haftalık görevleri günlere göre planlamayı, görevlere saat ve etiket eklemeyi ve tamamlanma durumlarını takip etmeyi sağlayan sade bir mobil planlama uygulamasıdır. Kullanıcılar önceki ve sonraki haftalar arasında geçiş yapabilir, görevlerini yeniden sıralayabilir ve planlarını cihazlarında saklayabilir.

## Uygulama Künyesi

- **Mobil framework:** React Native
- **Geliştirme platformu:** Expo SDK 57
- **Programlama dili:** TypeScript
- **Arayüz:** React Native bileşenleri
- **Yerel veri depolama:** AsyncStorage
- **Ek kütüphaneler:** React Native DateTimePicker, React Native Safe Area Context
- **Hedef platformlar:** Android, iOS ve web
- **Backend:** Harici sunucu veya veritabanı kullanılmıyor
- **Veri yaklaşımı:** Görevler cihazın yerel depolama alanında tutuluyor

## Çalıştırma

```bash
npm install
npm start
```

Platforma göre çalıştırmak için:

```bash
npm run android
npm run ios
npm run web
```
